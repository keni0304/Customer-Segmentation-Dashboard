# Customer Segmentation Dashboard

## Project Overview
This Power BI project analyzes customer demographics and purchasing behavior to identify customer segments.

## Tools Used
- Power BI
- DAX
- CSV Dataset

## Features
- Customer Segmentation
- Income Analysis
- Spending Score Analysis
- Age Group Analysis
- Interactive Filters
- Business Insights Dashboard

## Dashboard Preview

![Dashboard](Screenshots/Dashboard.png)

## Customer Segments
- Premium Customers
- Loyal Customers
- Potential Customers
- Budget Customers

## Key Insights
- Premium customers have high income and high spending.
- Potential customers have high income but lower spending.
- Loyal customers spend actively despite lower income.
- Budget customers may respond well to promotions.
